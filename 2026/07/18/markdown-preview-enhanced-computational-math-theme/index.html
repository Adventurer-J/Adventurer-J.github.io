先确认适用范围

这份主题面向 VS Code 扩展 Markdown Preview Enhanced（下文简称 MPE），使用的是扩展提供的 style.less 自定义入口。它不通过 VS Code 内置预览的 markdown.styles 加载，也不应粘贴到 settings.json。

推荐选择工作区配置。样式只影响当前项目，便于随项目迁移，也不会改变其他 Markdown 仓库的预览外观。只有确定所有项目都使用同一排版时，才需要全局配置。

安装步骤

  1. 安装 Markdown Preview Enhanced

    在 VS Code 扩展面板中搜索 Markdown Preview Enhanced，确认扩展标识为 shd101wyy.markdown-preview-enhanced，完成安装后重新载入窗口。

  2. 打开工作区样式文件

    按 Ctrl + Shift + P；macOS 使用 Cmd + Shift + P。运行下面的命令：

    Markdown Preview Enhanced: Customize CSS (Workspace)

    扩展会打开当前工作区使用的 style.less。通过命令打开比手动猜测配置目录更稳妥。

  3. 覆盖 style.less

    先备份原内容，再把下载文件中的全部 Less 规则复制到 style.less，保存文件。不要在这里加入 JSON 设置；该文件只接受 CSS 或 Less。

  4. 打开并刷新增强预览

    打开 Markdown 文件，运行 Markdown Preview Enhanced: Open Preview to the Side。若预览已经打开，点击预览右上角的刷新按钮，让扩展重新把 Less 编译为 CSS。

功能说明

01 / TYPOGRAPHY

清晰的长文层级

正文采用中英文字体回退链，标题使用无衬线字体；控制段落与标题间距，适合笔记、教程和项目说明。

02 / DETAILS

特殊内容兼容

兼容 KaTeX、MathJax 与 mjx-container，避免行内特殊内容误套代码框，并保持稳定的上下留白。

03 / TABLES

清楚的比较表

表格整体居中、数字等宽，保留表头与上下边线，弱化内部网格，适合选项、状态和版本对比。

04 / CODE

代码与行内标识

行内代码保持紧凑，代码块使用浅底、细边与左侧强调线，长行可横向滚动。

05 / STRUCTURE

摘要与提示环境

内置摘要、定义、备注和警告等可复用结构，帮助长文快速区分关键信息。

06 / OUTPUT

打印与 PDF

打印时切换为黑白文字、缩小字号，并尽量避免代码块、表格、图片和提示区跨页断裂。

让长文保持稳定节奏

长篇内容最容易被过密的标题、表格和代码打断。主题通过一致的段落间距与容器宽度建立阅读节奏，并为宽表提供横向滚动而不是强行压缩字号。

.markdown-preview.markdown-preview {
  max-width: 960px;
  line-height: 1.78;
}

table {
  min-width: 72%;
  font-variant-numeric: tabular-nums;
}

表格默认居中并使用等宽数字，适合比较版本、状态和完成时间：

| Version | Status | Updated |
|:--|:--|--:|
| 1.0 | Stable | 2026-07-18 |
| 1.1 | Preview | 2026-08-12 |

使用摘要和提示环境

MPE 允许在 Markdown 中保留 HTML。给内容添加主题已经定义的类名，就能得到结构清楚的信息块：

<div class="abstract">
这篇笔记说明目标、关键步骤与最终结果。
</div>

<div class="remark">
这里补充一个不会打断正文的实现细节。
</div>

<div class="warning">
修改配置前先备份现有 style.less。
</div>
类名显示标签适用内容
.abstract摘要目标、范围与最终结果
.definition定义术语与必要背景
.remark备注实现细节与补充信息
.warning注意风险、限制与重要提醒

按项目微调

建议把个性化覆盖写在 style.less 最后。后出现的规则优先级更高，升级主题时也更容易定位自己的修改。

目标覆盖示例
缩窄正文max-width: 960px;
放大正文font-size: 18px;
扩大图片img { max-width: 100%; }
让表格占满正文table { width: 100%; }
 
.markdown-preview.markdown-preview {
  /* 放在下载主题的末尾 */
  max-width: 960px;

  img {
    max-width: 100%;
  }
}

导出 PDF

主题中的 @media print 会在导出阶段启用：页面去掉屏幕预览留白，字体切换为黑色，表格改为全宽，并为代码块、表格、图片和提示区设置避免跨页。最终分页仍受纸张尺寸、浏览器打印引擎和内容高度影响，导出前应检查预览中的分页位置。

常见问题

现象检查方法
保存后没有变化确认打开的是 MPE 预览而非 VS Code 内置预览，然后点击预览右上角刷新按钮。
Less 编译报错检查是否把 settings.json 的 JSON 内容误贴进 style.less，并检查括号是否成对。
只有一个项目生效这是工作区配置的预期行为；如需全局生效，改用 Customize CSS (Global)。
公式仍带代码框确认最终文件完整复制，尤其不要遗漏清理公式内部 code 样式的规则。
表格过宽减少非必要列或缩短表头；宽表在屏幕上应优先保持数据完整，而不是强制压缩字号。
配置边界：这份 Less 只改变 MPE 的渲染结果，不改变 Markdown 源文件、VS Code 编辑器配色或其他 Markdown 扩展的预览。

命令名称、style.less 入口和刷新行为以 Markdown Preview Enhanced 的官方自定义 CSS 文档为准。
